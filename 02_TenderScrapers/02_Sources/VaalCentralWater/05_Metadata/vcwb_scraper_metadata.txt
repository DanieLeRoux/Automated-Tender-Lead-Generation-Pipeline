Purpose
-------
The scraper monitors the VCWB advertised tenders webpage, extracts advertised tender notices, stores raw outputs for audit/debugging, filters to currently open tenders, applies a simple priority score, and maintains master, delta, updates, and top-delta Excel outputs.

Optional Run Arguments
----------------------
--include-expired
Includes tenders where the closing date has already passed.

--top-delta-limit 50
Changes the maximum number of rows written to vcwb_top_delta.xlsx. Use 0 to include all qualifying delta rows.

--top-delta-min-score 3
Sets the minimum weight_score required for inclusion in vcwb_top_delta.xlsx.

--state-file "path"
Overrides the default JSON state file used to store seen opportunity keys.

Data Extraction Method
----------------------
The scraper fetches the public VCWB advertised tenders webpage and saves the full HTML as vcwb_raw_page.html.

It then parses the visible webpage content using BeautifulSoup. The parser creates a stream of visible text and document links, identifies tender blocks using reference number patterns, and extracts each notice into a structured row.

The parser is designed around VCWB/Bloem Water reference number formats such as:
VCW...
VCWB...
BW...

Unique Identifier
-----------------
The scraper uses opportunity_key as the unique tender identifier.

Format:
vcwb:<normalised reference number>

Example:
vcwb:vcw/...

Filtering Logic
---------------
Raw outputs are unfiltered and preserve the parsed webpage result.

Clean outputs are filtered by default to only include tenders where:
closing_date is present; and
closing_date >= today's date.

Expired tenders are excluded by default unless --include-expired is used.

Scoring Logic
-------------
All records are from VCWB, so priority_client_match is set to True for all rows.

The weight_score is currently based on description keyword matches only.

Current scoring:
Each matched description keyword = 1 point.

weight_score = description_keyword_match_count

Top Delta Logic
---------------
vcwb_top_delta.xlsx is created from vcwb_delta.xlsx only.

Rows are sorted by:
1. weight_score descending
2. closing_date ascending
3. date_uploaded ascending

Default top-delta settings:
Top delta limit: 20
Minimum score: 0

Delta Logic
-----------
vcwb_delta.xlsx contains tenders from the current run that are not already present in the existing master file, based on opportunity_key.

Updates Logic
-------------
vcwb_updates.xlsx contains existing tenders whose operational hash has changed since the previous master file.

Hash / Change Detection Fields
------------------------------
The following fields are used to determine whether an existing tender has materially changed:

description
date_uploaded
closing_date
document_names
document_urls
notice_type

Document names and URLs are included because VCWB may publish addenda, errata, extensions, or revised tender documents.

Master Logic
------------
vcwb_master.xlsx stores the latest current snapshot by opportunity_key.

When an existing opportunity_key appears again, the newly fetched row is preferred and the master is deduplicated by opportunity_key.

Excel Output Structure
----------------------
Each Excel output is written with a dedicated worksheet and Excel-style table where rows exist.

Worksheets:
Master: vcwb_master.xlsx
Delta: vcwb_delta.xlsx
Updates: vcwb_updates.xlsx
Top_Delta: vcwb_top_delta.xlsx
Raw_Data: vcwb_raw_full.xlsx

Current Limitations / Notes
---------------------------
The scraper depends on the public VCWB webpage structure. If VCWB changes the layout, reference number format, or date labels, the parser may need to be updated.

The scraper does not log in to any supplier portal and only uses publicly visible information.

The scraper does not currently download or parse the tender documents themselves. It captures document names and document URLs only.

If tender details are only contained inside PDFs or Word documents, those details will not be available unless a second-stage document parser is added later.

Recommended Daily Use
---------------------
Run once per day.
Review vcwb_top_delta.xlsx first.
Then review vcwb_delta.xlsx for all new entries.
Review vcwb_updates.xlsx for changes to existing opportunities.
Use vcwb_raw_full.xlsx and vcwb_raw_page.html for troubleshooting or audit checks.
