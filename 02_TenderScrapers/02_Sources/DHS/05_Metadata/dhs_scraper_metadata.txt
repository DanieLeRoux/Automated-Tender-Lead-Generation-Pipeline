DHS Tender Scraper Metadata

Scraper name:
Department of Human Settlements Tender Scraper

Script file:
dhs_tender_pull_and_clean.py

Source organisation:
National Department of Human Settlements (DHS)

Source URL:
https://www.dhs.gov.za/tenders

Purpose:
The scraper monitors publicly advertised tender opportunities from the Department of Human Settlements tenders page and maintains raw, master, delta, updates, and top-delta Excel outputs for tender tracking and daily review.

Scraper type:
Hybrid HTML / Selenium scraper

Reason for scraper type:
The DHS tenders page uses tabbed content sections and may initially load content dynamically. The scraper first attempts to parse the static page and then falls back to Selenium-rendered HTML where required.

Output logic:
- Raw outputs retain the scraped tender data for audit and debugging.
- Master contains the latest cleaned tender snapshot.
- Delta contains newly identified tender opportunities.
- Updates contains existing opportunities where monitored fields have changed.
- Top Delta contains the highest-scoring new opportunities from the current run.

Current tender filtering:
By default, the cleaned outputs keep only tenders where:
- closing_date is present; and
- closing_date is greater than or equal to the scraper run date.

Cancellation filtering:
By default, cancellation / withdrawal notices are excluded from the cleaned operational outputs.

Raw data treatment:
Raw outputs remain unfiltered so the source data can be checked if the clean outputs appear incomplete or incorrect.

Deduplication key:
opportunity_key

Update detection:
The scraper calculates a row hash using key tender fields. If the same opportunity_key exists in the master but the hash changes, the record is written to the updates file.

Scoring purpose:
The weight_score is used to prioritise tender opportunities for daily review. The score is intended as a screening aid, not a final bid/no-bid decision.

Scoring basis:
The scraper applies keyword-based and notice-type/source relevance scoring to identify opportunities aligned to consulting, engineering, infrastructure, project management, housing, construction, advisory, feasibility, and related professional service opportunities.

Known limitations:
- The scraper depends on the public DHS website structure.
- If DHS changes the tab structure, URL pattern, or tender detail page layout, the parser may require adjustment.
- The scraper only captures publicly available data.
- It does not log into any restricted portal.
- PDF or attachment contents are not deeply parsed unless exposed as text or links on the tender detail page.
